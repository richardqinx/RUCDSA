# 数据结构实验 02

## 功能简介

本项目使用 GNU C11 实现一个简单的终端计算器，包含：

- 线性表的添加、插入、删除、修改、查找和遍历；
- 向量加法、减法和夹角余弦计算；
- 顺序表多项式的加减、乘法和求导；
- 链表多项式的加减、乘法和求导。

底层实现使用自定义的 `vec` 动态数组和循环双向链表。

## 编译说明

在项目根目录执行：

```sh
make
```

默认使用 GNU C11 标准编译，生成可执行文件 `calculator`。

编译参数包括 `-std=gnu11 -Wall -Wextra -O2`，链接时使用数学库 `-lm`。

清理编译文件：

```sh
make clean
```

## 使用说明

运行程序：

```sh
./calculator
```

在主菜单中选择线性表、向量、顺序表多项式或链表多项式功能。菜单支持方向键或 `j`/`k` 移动，按 Enter 确认，按 `Esc` 或 `q` 返回或退出。

运行测试：

```sh
make test
```
